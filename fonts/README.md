# Portfolio display font

Cormorant Garamond, Christian Thalmann / Cormorant project. Local Latin variable font, weights 400–600.

CSS source: https://fonts.googleapis.com/css2?family=Cormorant+Garamond:wght@400..600&display=swap
Binary source: https://fonts.gstatic.com/s/cormorantgaramond/v21/co3bmX5slCNuHLi8bLeY9MK7whWMhyjYqXtK.woff2
License: Cormorant-Garamond-OFL.txt (SIL OFL 1.1).

Only ordinary portfolio pages use this font. Opening Japanese remains the accepted system Gothic stack.

Fan edition local display fonts (2026-10-11):
- Anton Regular, family Fan Condensed. Google Fonts ofl/anton/Anton-Regular.ttf, license Anton-OFL.txt.
- Permanent Marker Regular, family Fan Brush. Google Fonts apache/permanentmarker/PermanentMarker-Regular.ttf, license PermanentMarker-LICENSE.txt (Apache 2.0).
- Press Start 2P Regular, family Fan Pixel. Google Fonts ofl/pressstart2p/PressStart2P-Regular.ttf, license PressStart2P-OFL.txt.
All three fetched from the official google/fonts repository at https://github.com/google/fonts and served locally with font-display: swap. No remote font call at runtime.
